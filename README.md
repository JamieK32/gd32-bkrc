# GD32F4xx 省赛智能控制系统

基于 GD32F4xx 微控制器的省级竞赛智能控制系统，采用模块化设计理念，集成了丰富的传感器和执行器，支持多任务实时控制和人机交互界面。

## 项目特色

- **🏗️ 模块化架构**：采用分层设计，BSP层、驱动层、应用层分离
- **⚡ 实时操作系统**：基于 FreeRTOS，支持多任务并发执行
- **🔧 丰富外设支持**：30+ 传感器和执行器模块
- **🖥️ HMI交互界面**：集成串口屏人机界面系统
- **🎤 语音控制**：支持小创语音识别和控制
- **📡 多种通信方式**：UART、I2C、SPI、USB等

## 📁 项目结构

### 🖥️ 01-省赛屏幕文件
人机交互界面相关文件
- `省赛.HMI`: 串口屏配置文件，定义界面布局和交互逻辑

### 💻 02-省赛源码
核心源代码，采用分层架构设计

#### 🔧 BSP (板级支持包)
硬件抽象层，提供底层外设接口
- **ADC**: 模数转换器驱动
- **EXTI**: 外部中断管理
- **I2C**: I2C总线通信
- **Timer**: 定时器功能
- **USART**: 串口通信

#### 📚 Firmware (固件库)
- **CMSIS**: ARM标准接口，支持GD32F405/407/450
- **GD32F4xx_standard_peripheral**: 官方标准外设库
- **GD32F4xx_usb_library**: USB设备和主机功能

#### ⚙️ FreeRTOS
实时操作系统核心
- 任务调度和管理
- 队列和信号量机制
- 内存管理 (heap_4)
- ARM Cortex-M4移植层

#### 🔌 Modules (传感器模块)
丰富的传感器和执行器驱动库

**环境传感器**
- `dht11`: 温湿度传感器
- `ds18b20`: 温度传感器
- `bh1750`: 光照强度传感器
- `smoke`: 烟雾传感器
- `flame`: 火焰传感器
- `alcohol`: 酒精传感器

**运动控制**
- `motor`: 直流电机控制
- `step_motor`: 步进电机驱动
- `servo`: 舵机控制
- `mpu6050`: 六轴姿态传感器
- `hmc5883l`: 三轴磁力计

**显示与交互**
- `oled`: OLED显示屏
- `nixie`: 数码管显示
- `led`: LED指示灯
- `rgb_led`: RGB彩灯
- `key`: 按键输入
- `beep`: 蜂鸣器

**通信模块**
- `rc522`: RFID读卡器
- `c1016`: 串口通信模块
- `usart_lcd`: 串口液晶屏

**其他功能**
- `ultrasonic`: 超声波测距
- `hx711`: 称重传感器
- `lock`: 电子锁控制
- `fan`: 风扇控制

#### 🎯 USER (用户应用)
应用层代码
- `main.c`: 主程序入口
- `task_manager.c`: 任务管理器
- `gd32f4xx_it.c`: 中断处理程序
- `button_callback.c`: 按键回调处理

## 🏗️ 系统架构

### 分层设计架构
```
┌─────────────────────────────────────┐
│        应用层 (USER)                 │  任务管理、业务逻辑
├─────────────────────────────────────┤
│      模块层 (Modules)               │  传感器驱动、执行器控制
├─────────────────────────────────────┤
│        BSP层                        │  硬件抽象层
├─────────────────────────────────────┤
│     FreeRTOS操作系统                │  任务调度、资源管理
├─────────────────────────────────────┤
│      固件库 (Firmware)              │  HAL层、标准外设库
├─────────────────────────────────────┤
│     硬件层 (GD32F4xx)               │  微控制器硬件平台
└─────────────────────────────────────┘
```

### 核心特性
- **实时多任务**: 基于FreeRTOS的抢占式任务调度
- **模块化驱动**: 30+传感器执行器模块，即插即用
- **队列通信**: 任务间安全数据传输机制
- **中断驱动**: 高效的事件响应机制
- **内存管理**: heap_4内存管理算法
- **错误处理**: 完善的错误检测和恢复机制

## ⚡ 快速开始

### 环境要求
- **IDE**: Keil MDK-ARM v5.x 或更高版本
- **编译器**: ARM Compiler v6.x
- **调试器**: J-Link 或 ST-Link
- **目标芯片**: GD32F407xx 系列

### 构建步骤

1. **环境准备**
   ```bash
   # 确保安装Keil MDK并配置GD32F4xx器件包
   # 连接J-Link调试器到目标板
   ```

2. **项目构建**
   - 打开 `02-省赛源码/Project/TEST.uvprojx`
   - 选择目标芯片型号 (GD32F407VET6)
   - 配置调试器类型和参数
   - 编译项目 (F7) 生成 `TEST.axf`

3. **程序下载**
   - 连接目标板电源和调试器
   - 下载程序到Flash (F8)
   - 复位运行或调试执行

### 配置说明
- **时钟配置**: 168MHz系统时钟
- **堆栈大小**: 每任务2KB栈空间
- **任务优先级**: 0-7级，数字越大优先级越高
- **串口配置**: 115200波特率，用于调试输出

## 🎮 使用方法

### 系统启动流程
1. **硬件初始化**: 时钟、GPIO、外设配置
2. **RTOS启动**: 创建任务队列和信号量
3. **任务创建**: 启动各功能模块任务
4. **HMI初始化**: 串口屏界面显示
5. **进入调度**: FreeRTOS任务调度循环

### 主要交互方式
- **HMI触摸屏**: 主要控制界面，支持参数设置和状态显示
- **串口调试**: 通过USART0 (115200) 输出调试信息
- **按键输入**: 物理按键支持紧急控制
- **语音控制**: 小创语音模块语音识别控制
- **RFID卡片**: RC522模块刷卡识别功能

### 调试输出
系统集成了分级日志输出功能：
```c
LOG_I("信息级日志");  // 一般信息
LOG_W("警告级日志");  // 警告信息  
LOG_E("错误级日志");  // 错误信息
```

## 🔧 二次开发

### 添加新模块
1. 在 `Modules/inc/` 添加头文件
2. 在 `Modules/src/` 添加源文件
3. 在 `task_manager.c` 中创建对应任务
4. 更新 `main.c` 中的初始化流程

### 任务管理示例
```c
// 创建新任务
TaskHandle_t newTaskHandle = NULL;
bool result = start_task(
    NewTaskFunction,    // 任务函数
    "NewTask",         // 任务名称
    3,                 // 优先级
    &newTaskHandle     // 任务句柄
);
```

### 模块通信
```c
// 队列通信示例
QueueHandle_t dataQueue = xQueueCreate(10, sizeof(SensorData));
xQueueSend(dataQueue, &sensorData, portMAX_DELAY);
```
